## 🌱 Overview

The **common** module provides foundational shared utilities and reusable
components used across the Entiqon ecosystem.

It promotes consistency, code reuse, and well-tested implementations for common
development tasks.

---

## 🚀 Quick Start

```bash
go get github.com/entiqon/common
```

---

## 📦 Subpackages

| Package | Description |
|---------|-------------|
| [🧩 common/errors](../common/errors/README.md) | Structured error types with cause, reason, and process stage. |
| [🧩 common/extension](../common/extension/README.md) | Type parsers, collections, object helpers, and shortcuts. |
| [🧩 common/ptr](../common/ptr/README.md) | Generic pointer utilities for working with optional values. |
| [🧩 common/text](../common/text/README.md) | String padding, truncation, and presentation utilities. |
